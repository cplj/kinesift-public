KinesiftComparisonSource

Local · Observable · Resettable

Run a local agent.
Observe its effects.
Keep the evidence.

Kinesift observes local agent containers from the host, records side effects and forbidden path mutations, and seals the records with a local hash chain. Attach the observation to existing Harbor trial results. The synthetic ticket evaluator remains available.

Install from GitHub

Requires Python 3.10 or later and Git:

python3 -m venv /tmp/kinesift-demo-venv
. /tmp/kinesift-demo-venv/bin/activate
pip install git+https://github.com/cplj/kinesift-public
printf '%s\n' '{"task":"route-0","seed":11,"actions":[{"action":"set_queue","value":"finance"}]}' | kinesift run

Expected: SUCCEEDED, accepted: true, exit 0. Omit actions to get an observation: UNKNOWN, accepted: null, exit 3. Each call starts fresh.

Read the evidence with its limits

The comparison report covers two deterministic scripts in this synthetic environment. Both favorable and unfavorable results are retained.

The external observer has startup and sampling gaps and cannot prove a clean history; its local hash anchor is not independent attestation. The synthetic evaluator grades only submitted actions. Neither path isolates untrusted code or proves model performance, customer acceptance or deployment safety.
